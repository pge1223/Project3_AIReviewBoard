## 실험 4 — 근거 기반성: 지적↔원문 문장 1:1 검증 (issue_refs)

| 입력(지적 속 인용) | 판별 결과 | 화면 표시 |
|---|---|---|
| 원문에 실제 있는 인용 `(p.2) '구체적인 수치 목표는 추후에 정할 예정'` | `verified: true` | STEP 1 "제출 문서 근거"로 표시 |
| 원문에 없는(지어낸) 인용 | `verified: false` | **표시되지 않음** |
| 인용이 없는 지적 | ref 없음 | 항목 단위 인용으로 폴백 |

- 부분 문장이 더 긴 인용에 포함되면 **가장 완전한 인용 1개만** 표시(중복 제거 일반 규칙 — 전 항목 적용).
- 인용 표시는 색인된 evidence의 **KURE 의미 유사도 score 내림차순** 상위 4개.
